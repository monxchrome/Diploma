# Consolidated Limitations

- Cloud model output and provider APIs may change; deterministic output is not guaranteed.
- Actual quality depends on the selected models, evidence, prompts, and deployment configuration.
- Multi-agent execution costs more and takes longer than a focused run.
- LLM judges can be biased; human evaluation can be limited or inconsistent.
- Synthetic and bounded datasets cannot establish general real-world performance.
- Qwen-through-Ollama results depend on exact model, quantization, driver, and hardware.
- Live web results are time-varying and constrained by the server safety policy.
- A public share link is access control, not DRM; recipients can still copy visible content.
- PDF accessibility depends on the selected renderer and requires manual verification.
- The project has no formal legal, privacy, or security certification.
- There is no complete offline-first mode, native mobile app, enterprise SSO, fine-tuning, or automatic proof of correctness.
- Grounding/citation controls reduce but cannot guarantee the absence of hallucinations.
- Recommendations are decision support, not legal, financial, medical, or other professional advice.
- Production performance depends on deployment hardware, model availability, database state, and network conditions.
- This working tree has no executed full regression, migration drill, restore drill, or real benchmark artifact; it must not be represented as a release-ready production build.
