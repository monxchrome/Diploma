# Feature Flag Registry

Flags are server-owned environment settings. The web application only consumes server responses and public environment display metadata; it must not enable a server capability itself. Defaults below are from `.env.example`; production values are explicit in `docker-compose.prod.yml` and the protected deployment environment.

| Flag                                                                                     | Owner             | Development / test / demo default | Production default          | Dependency and security impact                                                                 | Release status |
| ---------------------------------------------------------------------------------------- | ----------------- | --------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------- | -------------- |
| `BILLING_ENABLED`                                                                        | Billing           | enabled                           | enabled                     | Enables entitlement checks; billing provider remains server-owned.                             | Supported      |
| `BILLING_PROVIDER`, `BILLING_FAKE_PROVIDER_ENABLED`                                      | Billing           | fake / enabled                    | stripe / disabled           | Fake billing is rejected by production validation unless an explicitly unsafe override is set. | Supported      |
| `EXTERNAL_RESEARCH_ENABLED`                                                              | Research          | disabled                          | disabled                    | Requires server-side provider policy and key; private-network fetches remain blocked.          | Supported      |
| `REPORT_EXPORT_*`                                                                        | Reports           | enabled                           | explicit operator choice    | Queued private exports; remote assets default off.                                             | Supported      |
| `REPORT_SHARE_*`                                                                         | Reports           | enabled                           | explicit operator choice    | Public sharing changes exposure; expiry, revocation, and entitlement checks apply.             | Supported      |
| `REPORT_COMMENTS_ENABLED`, `COLLABORATION_NOTIFICATIONS_ENABLED`                         | Reports           | enabled                           | explicit operator choice    | Alters collaboration surface only after server authorization.                                  | Supported      |
| `REPORT_BRANDING_ENABLED`                                                                | Reports           | enabled                           | explicit operator choice    | SVG sanitization remains opt-in.                                                               | Supported      |
| `BENCHMARK_ENABLED`, `BENCHMARK_HUMAN_EVALUATION_ENABLED`, `BENCHMARK_LLM_JUDGE_ENABLED` | Benchmark         | disabled                          | disabled                    | Provider calls/costs remain disabled until an administrator configures profiles.               | Supported      |
| `OPENAI_*`, `ANTHROPIC_*`, `OLLAMA_*`                                                    | Benchmark runtime | empty / local-only                | secret-managed / local-only | Keys never cross the API boundary; remote Ollama is prohibited by default.                     | Supported      |

There is no generic runtime flag registry or browser mutation endpoint. Unrecognized raw environment variables are not a dependable configuration interface and are ignored by portions of the current settings stack; RRA-007 documents this limitation. Deployment changes must use only the names in `.env.example`, `.env.production.example`, and the validated application schemas. `pnpm release:preflight` validates the release metadata and scans tracked text, but it is not a substitute for a deployment secret manager or a complete environment allowlist.
