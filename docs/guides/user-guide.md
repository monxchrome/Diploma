# User Guide

1. Register or sign in, then create or select a project.
2. Add only material you are authorized to process. Upload supported documents to a project knowledge base and wait for ingestion readiness.
3. Ask a decision question from Home. Choose Focused or Multi-perspective processing and enable external research only when the project entitlement/policy permits it.
4. Read the recommendation together with citations, conflicts, assumptions, uncertainty, and decision-readiness indicators. Treat the output as decision support.
5. Export only an immutable report snapshot. Share links should be scoped, expiring, and revoked when no longer needed.
6. Collaborate through project membership and comments; do not paste secrets, sensitive personal data, or provider credentials.

If an analysis, source, export, or share action fails, retain the request ID and contact the project administrator. Product availability and feature entitlements depend on the deployment configuration.
