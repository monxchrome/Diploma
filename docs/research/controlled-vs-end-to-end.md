# Controlled Evidence and End-to-End

Controlled evidence uses an immutable per-case package with identical hashes across selected variants. Retrieval and live research are not invoked, so the result isolates configured architecture and model behaviour more closely.

End-to-end runs record a separate snapshot and are useful for pipeline evaluation, but retrieval, research availability and changing sources are confounders. Results from the two protocols are reported separately and are not pooled by default.
