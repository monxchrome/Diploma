# Research Questions

RQ1 compares single-agent and fixed multi-agent architectures under identical frozen evidence. RQ2 compares pinned OpenAI, Anthropic and Qwen-family profiles through the Ollama runtime. RQ3 tests whether fixed heterogeneous role assignment changes grounding, decision usefulness, cost, latency and stability. RQ4 compares an independent cross-provider critic with a same-provider critic. RQ5 measures how conclusions differ between controlled evidence and end-to-end pipeline conditions.

No question is treated as answered before a completed, versioned run with adequate sample size and stated limitations.
