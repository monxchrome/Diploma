# Benchmark Design

Each suite specifies questions, hypotheses, a frozen dataset version, variants, role assignments, rubric and analysis plan. Runs select variants, protocol, repetitions, saved randomization seed and a budget protocol before queueing. Case/variant/repetition is the unit of execution; same-case paired observations are the unit of comparison.

V1–V10 are fixed templates. Custom heterogeneous mappings are explicit, versioned variants rather than runtime user input.
