# Entitlements

Entitlements are Zod-validated typed limits for projects, members, knowledge bases, documents, storage, upload size, analysis modes, research, experiments, exports, concurrency, retention, queue priority, and support level.

The resolver reads a subscription's stored plan code and version first. ACTIVE, TRIALING, PAST_DUE during its provider period, and scheduled cancellation during its remaining period retain paid access. UNPAID, PAUSED, INCOMPLETE, EXPIRED, and elapsed cancellation use FREE creation limits without deleting data.
