# Thesis Defence Summary

## Problem

Decision makers often need to reconcile project documents, uncertain evidence, and multiple perspectives without treating a language-model response as an authoritative answer.

## Goal and objectives

The goal is to design and implement a decision-intelligence platform that preserves project-scoped evidence, produces citation-aware decision support, and permits controlled evaluation of bounded agent configurations. The objectives are to establish service boundaries, private knowledge ingestion, grounded retrieval, bounded single/multi-agent analysis, controlled external evidence, immutable reporting/collaboration, governed billing/quotas, and reproducible benchmark infrastructure.

## Claimed engineering contribution

The project combines evidence-scoped retrieval, explicit citations and uncertainty, a bounded multi-agent workflow, immutable report snapshots, and a separate reproducible benchmark lane under one authorization and operational model. This is an implementation contribution, not a claim that the system proves model correctness or universally improves decisions.

## Evidence discipline

No completed benchmark result artifact was observed in this working tree. Therefore the defence must present hypotheses and methodology, not performance numbers, rankings, statistically significant findings, or a claim of superiority. See [benchmark evidence status](benchmark-evidence.md).
