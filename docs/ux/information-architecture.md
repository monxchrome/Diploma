# Information Architecture

Primary navigation is Home, Projects, Analyses through Home and project pages, Experiments, and Settings. Search opens a command palette for accessible workspace destinations and projects.

Home owns the new analysis composer, example questions, running analyses and recent analyses. Projects own sources and the existing technical project capabilities. Billing and usage remain under Settings. Knowledge-base implementation detail is presented as **Sources** in user-facing project context rather than a global navigation item.

Technical run, research, source and conflict pages are intentionally retained as deep-linkable power-user views and are grouped under Technical details from the report.
