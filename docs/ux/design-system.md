# Design System

The Phase 9 web surface uses the existing Tailwind primitives and `Button` component. It introduces a quiet neutral canvas, white elevated surfaces, teal action and focus color, rounded cards, 40px-or-larger controls, compact status pills and consistent empty/loading/error panels.

The CSS token layer defines background, foreground, muted text, border, surface, primary, warning and destructive colors. It supports system light and dark color schemes. New components use the token palette and visible focus rings rather than adding a UI library.
