# Phase 9 Manual Test Plan

Test signed-in new and existing users at 1440×900, 1024×768, 768×1024 and 390×844.

1. Land on Home after registration or login and confirm the composer is the only primary Home action.
2. Create a project inline, add a document, keep the question during upload, then start one analysis.
3. Refresh before starting and confirm the local draft is restored. Trigger a quota rejection and confirm the draft remains.
4. Verify one-project and last-used-project selection, all-ready-source default, explicit web-research choice and collapsed Advanced panel.
5. Leave an active analysis, return through Home, confirm friendly progress, stop it and retry once.
6. Open a completed result, source preview and Technical details. Confirm rejected sources are not treated as evidence.
7. Use keyboard only: composer, command palette, source preview and Escape. Check visible focus at 200% zoom and reduced motion.
8. On mobile, check the drawer, composer, selector, report, source bottom sheet and absence of horizontal scrolling.
