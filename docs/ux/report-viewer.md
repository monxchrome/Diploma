# Report Viewer

Completed analyses open on the recommendation-first view. The view presents the recommendation, summary, rationale, risks, missing information, next steps and non-empty report sections. A limited result has a prominent, plain-language alert.

Source chips open an adjacent preview dialog. Project and web sources remain visually distinct. The report does not describe rejected web inputs as trusted evidence. Quality and readiness metrics are collapsed under Details; the existing technical routes remain available without placing graph vocabulary in the main reading flow.
