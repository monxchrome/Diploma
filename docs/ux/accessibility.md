# Accessibility

The composer has a visible label, input help, keyboard submit behavior, an accessible attachment input, labels for project and source controls, and alerts for preserved-error states. Icon-only actions have accessible names.

The sidebar uses semantic navigation and becomes a dismissible mobile drawer. The command palette and citation preview use dialog semantics, Escape to close and autofocus on their close controls. Native confirmation is used for destructive cancellation and existing destructive project/source actions. Reduced-motion preferences remove transitions and animation; all new controls include focus-visible styles.

Manual verification remains required for assistive-technology reading order, native dialog behavior, 200% zoom and physical-device touch targets.
