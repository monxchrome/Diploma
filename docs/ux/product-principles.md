# Product Principles

- One visible primary action on the Home screen: **Analyze**.
- Ask for a decision first; configuration follows only when necessary.
- Prefer ready project sources and safe existing server defaults.
- Keep user input through navigation, upload errors, quota errors and transient failures.
- Describe outcomes in user language. Technical implementation remains available in Details.
- Never silently enable web research or change the requested scope.
- Treat limitations as part of the result, not a cosmetic error state.
