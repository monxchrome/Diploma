# Analysis Composer

The composer supports a multi-line question, Enter to start, Shift+Enter for a newline, source attachment, drag-and-drop, pasted browser files, a compact project selector and source selector.

With one accessible project it is selected automatically. A last used accessible project is preferred when several projects exist. If there is no project, the composer creates one inline with a name only and preserves the question.

All ready documents are selected by default. Users can narrow the source set in the compact selector. A new source uploads through the existing signed-upload and ingestion flow; an upload failure keeps the question and selection.

Advanced is closed initially. It contains friendly approach labels and the explicit web-research choice. It does not expose graph nodes, provider names, model names, reranker controls, fetch counts or specialist configuration.
