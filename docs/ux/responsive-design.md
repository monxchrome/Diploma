# Responsive Design

Desktop uses a persistent, optionally collapsed sidebar. Below the large breakpoint the sidebar becomes a modal drawer and the header exposes navigation and search controls. The Home composer stacks its controls and keeps its primary action full width on narrow screens.

Report cards change from two columns to one. Citation preview is a bottom sheet on small screens and a centred dialog on larger screens. New layouts use `min-w-0`, wrapping controls and bounded popover widths to avoid horizontal body scroll.
