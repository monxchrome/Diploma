# Privacy Review

The product processes user accounts, project content, documents, reports, audit/usage metadata, and optional provider interactions. The intended controls are project-scoped authorization, private object storage, minimized public share payloads, short-lived download URLs, logging redaction, and server-side credentials.

Operators must define the lawful basis, retention schedule, data-processing agreements, user-request process, geographic transfer posture, breach process, and any required DPIA for their own deployment. Do not upload confidential data to a demo environment. Controlled external research and cloud model providers can create additional transfer and retention obligations; enable them only after an operator review.

The repository does not provide legal advice, a formal privacy certification, or a completed deployment-specific privacy assessment.
